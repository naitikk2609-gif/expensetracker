## 1. Problem Statement
Managing daily expenses manually can make it difficult to keep track of total spending and understand which categories consume the most money.

The Simple Expense Tracker provides a basic command-line solution using Python. It allows users to enter expense information, store records, view expenses, calculate totals, compare category-wise spending, and identify the highest expense.

## 2. Project Scope
The project focuses on basic personal expense management through a command-line interface.

The scope includes:
- Recording daily expenses
- Storing expense name, category, and amount
- Displaying stored expenses
- Calculating total spending
- Calculating category-wise spending
- Finding the highest expense
- Saving records using a CSV file
- Loading saved records
- Handling basic invalid input

The project does not include online payments, bank integration, advanced databases, web applications, or authentication.

## 3. Target Users
- Students
- Beginners learning Python
- Individuals who want a simple way to record daily expenses

## 4. High-Level Features
### Add Expense
The user enters the expense name, category, and amount.

### View Expenses
The program displays stored expenses.

### Total Expense
The program calculates the total amount spent.

### Category Summary
The program groups expenses by category and calculates the amount spent in each category.

### Highest Expense
The program identifies and displays the expense with the highest amount.

### Save and Load Expenses
The program stores expense records in a CSV file and loads them when the application starts.

### Input Validation
The program handles invalid menu choices and invalid expense amounts.

## 5. Expected Outcome
The completed project provides a simple Python application through which a user can record expenses and obtain basic spending information.
