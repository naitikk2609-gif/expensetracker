## Project Overview
A beginner-level command-line Python project for recording and analyzing daily expenses.

## Features
- Add an expense
- View all expenses
- Calculate total expense
- Category-wise expense summary
- Find highest expense
- Save expense records
- Load saved expense records
- Basic input validation

## Technologies Used
- Python 3
- Command Line / Terminal
- CSV file storage
- Git and GitHub

## Python Concepts Used
Variables, input/output, conditions, loops, lists, dictionaries, functions, file handling, classes, and basic exception handling.

## How to Run
1. Install Python 3.
2. Open the project folder in a terminal.
3. Run:
```bash
python main.py
```
4. Follow the menu displayed by the program.

## Run Tests
```bash
python -m unittest discover -s tests
```
